## 1. COMPLETE COLOR SYSTEM

### Primary Colors:
**Luxora Navy (Primary Brand Color):** `#0A1F44`
- Deep, sophisticated navy blue
- Used for primary branding, navigation, and key accents
- Represents depth, sophistication, and architectural excellence

**Luxora Cream (Background):** `#F5F0E6`
- Warm cream background color
- Creates premium, warm foundation
- Used for main background and card backgrounds

**Luxora Gold (Accent):** `#D4AF37`
- Premium gold accent color
- Used for CTAs, highlights, and premium indicators
- Represents luxury, craftsmanship, and exclusivity

**Luxora Forest Green (Secondary Accent):** `#1A472A`
- Deep forest green for secondary accents
- Used for environmental/sustainability messaging
- Creates natural, organic feel

### Neutral Colors:
**Neutral Gray:** `#E8E8E8`
- Light gray for subtle separators and borders
- Creates clean, minimalist visual language

**Dark Gray:** `#333333`
- Used for secondary text and subtle accents
- Provides depth without overwhelming

**Pure White:** `#FFFFFF`
- Used for card backgrounds and section backgrounds
- Creates crisp, clean aesthetic

### Color Usage Guidelines:
- **Background:** Luxora Cream (`#F5F0E6`) for main background, Pure White (`#FFFFFF`) for cards/sections
- **Text:** Luxora Navy (`#0A1F44`) for headings, Dark Gray (`#333333`) for body text
- **Accents:** Luxora Gold (`#D4AF37`) for CTAs and highlights, Luxora Forest Green (`#1A472A`) for sustainability elements
- **Hover States:** Luxora Gold (`#D4AF37`) for hover effects on navy elements
- **Disabled States:** Neutral Gray (`#E8E8E8`) for disabled elements

### Color Combinations:
**Primary Combination:** Luxora Navy + Luxora Cream + Luxora Gold
**Secondary Combination:** Luxora Navy + Pure White + Luxora Forest Green
**Accent Combination:** Luxora Gold + Luxora Navy + Luxora Cream

## 3. LAYOUT SYSTEM

### Page Layout Principles:
- **Generous Whitespace:** Minimum 80px between sections, 40px between elements
- **Architectural Grid:** Clean, structured layouts with visible grid
- **Visual Hierarchy:** Clear section differentiation through spacing and typography
- **Content Flow:** Logical progression from hero → discovery → conversion
- **Section Balance:** Balanced visual weight across all sections

### Section Layout Types:

**Hero Section Layout:** Full-width hero with centered content
- Background: Luxora Cream or premium imagery
- Content: Centered alignment with generous padding
- CTAs: Gold buttons with Luxora Navy hover states

**Grid Section Layout:** Structured grid layouts
- Grids: 2, 3, or 4 columns based on content
- Card spacing: 30px between cards
- Visual rhythm: Consistent spacing and alignment

**Split Section Layout:** Split content layouts
- Left/right content split with imagery/content balance
- Spacing: 60px between split sections
- Visual balance: Equal visual weight on both sides

**Feature Section Layout:** Featured content layouts
- Large featured element with supporting content
- Emphasis on premium imagery and content
- Clear visual hierarchy with featured element prominence

### Layout Guidelines:
- **Minimum Section Height:** 400px for desktop, 300px for mobile
- **Maximum Section Width:** 1200px container width for desktop content
- **Container Padding:** 80px left/right for desktop, 40px for mobile
- **Visual Rhythm:** Consistent spacing creates editorial flow
- **Content Priority:** Most important content at top, conversion elements prominent

## 4. GRID SYSTEM

### Main Grid System:
**Desktop Grid:** 12-column grid with 24px gutters
- Container width: 1200px
- Column width: 100px each
- Gutters: 24px between columns
- Margin: 0px outside container

**Mobile Grid:** 4-column grid with 16px gutters
- Container width: 100% viewport
- Column width: flexible
- Gutters: 16px between columns
- Margin: 16px outside container

### Grid Usage:
**Hero Sections:** 12-column for desktop, 4-column for mobile
**Card Grids:** 3 columns (3 cards per row) for desktop, 1 column for mobile
**Feature Grids:** 2 columns (split layout) for desktop, 1 column for mobile
**Navigation Grid:** 12-column for desktop navigation, 4-column for mobile
**Footer Grid:** 5 columns for desktop footer, 1 column for mobile

### Grid Guidelines:
- **Responsive Breakpoints:** Desktop (>1024px), Tablet (768px-1024px), Mobile (<768px)
- **Grid Adaptation:** Columns reduce based on breakpoints
- **Card Alignment:** Cards align to grid for visual consistency
- **Image Placement:** Images respect grid boundaries for clean layout

## 5. SPACING SYSTEM

### Spacing Scale:
**Desktop Spacing:**
- XXL: 120px (section spacing)
- XL: 80px (between major sections)
- L: 60px (between subsections)
- M: 40px (between cards/items)
- S: 24px (within cards)
- XS: 16px (between small elements)
- XXS: 8px (minimal spacing)

**Mobile Spacing:**
- XL: 60px (section spacing)
- L: 40px (between major sections)
- M: 30px (between subsections)
- S: 20px (between cards/items)
- XS: 12px (within cards)
- XXS: 8px (between small elements)

### Spacing Guidelines:
**Section Spacing:** Use XL spacing (80px desktop, 60px mobile) between major sections
**Card Spacing:** Use M spacing (40px desktop, 30px mobile) between cards in grids
**Element Spacing:** Use S spacing (24px desktop, 20px mobile) between elements within sections
**Text Spacing:** Use XS spacing (16px desktop, 12px mobile) between text blocks
**Padding Rules:** Use XL padding for section containers, M padding for card containers

### Visual Rhythm:
- **Consistent spacing:** Creates editorial flow and premium feel
- **Hierarchical spacing:** Larger spacing for more important sections
- **Balanced whitespace:** Even distribution creates clean aesthetic
- **Architectural precision:** Exact spacing measurements for premium look
