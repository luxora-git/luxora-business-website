## 2. VISUAL DESIGN SYSTEM SPECIFICATIONS

### 2.1 Color Palette
**Primary Colors:**
– **Deep Navy:** #0A1F44 (for primary navigation and CTAs)
– **Cream:** #F5F0E6 (backgrounds and containers)
– **Gold:** #D4AF37 (accent for luxury elements)

**Secondary Colors:**
– **Forest Green:** #1A472A (alternate primary option)
– **Dark Gray:** #333333 (text and subtle accents)
– **Light Gray:** #E5E5E5 (dividers and subtle backgrounds)

**Accent Colors:**
– **Bronze:** #CD7F32 (for secondary CTAs)
– **Marble White:** #FFFFFF (clean backgrounds)
– **Charcoal:** #2C2C2C (dark mode elements)

### 2.2 Typography System
**Primary Fonts:**
– **Headings:** Playfair Display (serif for luxury feel)
– **Body:** Inter (clean, readable sans-serif)
– **Accent:** Cormorant Garamond (for luxury messaging)
– **Numbers:** Lato (clean sans-serif for pricing)

**Font Scale:**
– H1: 48px (hero headings)
– H2: 36px (section headings)
– H3: 24px (sub-headings)
– Body: 16px (main content)
– Small: 14px (captions, details)

**Font Weight Hierarchy:**
– Bold: 700 (primary headings)
– Semi-bold: 600 (secondary headings)
– Regular: 400 (body text)
– Light: 300 (captions, subtle text)

### 2.3 Spacing & Layout
**Grid System:**
– 12-column responsive grid
– Gutter: 24px
– Margin: 48px (desktop), 24px (mobile)

**Whitespace Principles:**
– Section padding: 80px top/bottom (desktop), 40px top/bottom (mobile)
– Element spacing: 24px between related elements
– Breathing room: Minimum 16px between unrelated elements

**Breakpoints:**
– Desktop: ≥1024px
– Tablet: 768px–1023px
– Mobile: ≤767px

### 2.4 Imagery Strategy
**Image Types:**
1. **Hero Images:** Luxury lifestyle shots, architectural beauty
2. **Portfolio Images:** Professional interior photography with consistent lighting
3. **Material Detail:** High-resolution finishes, textures, details
4. **Process Images:** Designer working, craftsmanship, installation
5. **Testimonial Images:** Discretionary client shots (optional)
6. **Brand Images:** Luxury brand logos, partnership displays

**Image Guidelines:**
– All images must be high-resolution (minimum 1920px width)
– Consistent lighting and color grading
– Professional photography standards
– Minimal stock imagery usage

## 4. CONVERSION FUNNEL OPTIMIZATION

### 4.1 Primary Conversion Paths

**Path A: Portfolio → Consultation**
```
1. User views portfolio
2. Likes specific project/style
3. CTA: "Schedule Similar Project"
4. VIP consultation booking form
5. Follow-up: Personal designer assignment
```

**Path B: Services → Estimator → Consultation**
```
1. User explores services
2. Uses bespoke estimator
3. Gets preliminary estimate
4. CTA: "Schedule Consultation for Detailed Quote"
5. VIP consultation booking
```

**Path C: Materials → Consultation**
```
1. User explores luxury finishes
2. Likes specific materials
3. CTA: "Schedule Consultation to Discuss Materials"
4. VIP consultation booking
```

### 4.2 CTA Strategy
**CTA Hierarchy:**

1. **Primary CTAs:** "Schedule VIP Consultation" (gold button, prominent placement)
2. **Secondary CTAs:** "Explore Portfolio", "View Materials Gallery" (navy button)
3. **Content CTAs:** "Learn More", "View Full Project" (subtle links)
4. **Calculator CTAs:** "Request Bespoke Estimate" (interactive forms)

**CTA Placement Rules:**
– Every section should have at least one CTA
– Primary CTAs appear in hero section and end of key pages
– Secondary CTAs appear in mid-page content sections
– Content CTAs appear within articles/portfolio items

### 4.3 Form Design & Booking System
**VIP Consultation Booking Form:**

```
Fields:
  - Name (required)
  - Email (required)
  - Phone (optional)
  - Project Type: Full Home / Modular / Renovation / Bespoke
  - Property Size: Apartment / Villa / Penthouse / Commercial
  - Preferred Style: Contemporary / Minimalist / Traditional
  - Budget Range: ₹5-10 lakhs / ₹10-20 lakhs / ₹20+ lakhs / Bespoke

  - Notes/Comments

Form Features:
  - Calendar integration for scheduling

**Bespoke Estimator Form:**

```

## 6. TECHNICAL IMPLEMENTATION RECOMMENDATIONS

### 6.1 Technology Stack
**Frontend Framework:**
– **React/Vue.js** for interactive components
– **TypeScript** for type safety
– **Tailwind CSS** for utility-first styling

**Backend Platform:**
– **Node.js/Express** or **Python/FastAPI** for API
– **PostgreSQL** for database
– **Redis** for caching

**CMS & Content Management:**
– **Custom CMS** for portfolio updates
– **Image optimization** for high-resolution photos
– **Video hosting** for project videos

### 6.2 Performance Optimization
**Image Optimization:**
– **WebP format** with fallback to JPEG
– **Responsive images** with srcset
– **Lazy loading** for portfolio images
– **CDN hosting** for all images

**Performance Targets:**
– **Page load time:** < 2 seconds
– **First Contentful Paint:** < 1.5 seconds
– **Largest Contentful Paint:** < 2.5 seconds

### 6.3 SEO Strategy
**Technical SEO:**
– **Structured data** for portfolio items
– **XML sitemap** with priority pages
– **Robots.txt** optimization
– **Meta tags** optimization

**Content SEO:**
– **Keyword strategy:** Luxury interior design, premium interiors, bespoke design
– **Location pages:** Mumbai luxury interiors, Delhi premium design
– **Material pages:** Italian finishes, premium hardware
– **Designer pages:** Expert designer profiles

### 6.4 Analytics & Conversion Tracking
**Tracking Setup:**
– **Google Analytics 4** for general analytics
– **Heatmap tools** for user behavior analysis
– **Conversion tracking** for booking forms
– **A/B testing** for CTAs and layouts

**Key Metrics:**
– **Booking form submissions**
